# SMB Check — ежемесячная проверка безопасности для малого бизнеса

Программа для Windows, которая раз в месяц проверяет домен клиента и выдаёт понятный отчёт на 1–2 страницы:
оценка A–F, три главных действия, что изменилось с прошлого раза. Сделана под модель «услуга по подписке»:
вы ведёте список клиентов, программа проверяет, вы отправляете отчёт и объясняете, что чинить.

Никаких внешних библиотек: только стандартный Python. Собирается в один `SMBCheck.exe`.

## Что проверяется

| Направление | Проверки |
|---|---|
| Почта | MX и провайдер (Яндекс 360, VK WorkSpace, Google, Microsoft 365…), SPF (+all, ?all, дубли, лимит 10 запросов), DMARC (нет / p=none / pct / sp / отчёты rua), DKIM по 30 известным селекторам и длина ключа |
| Сайт | сертификат (просрочен, самоподписан, чужое имя, истекает), TLS 1.0/1.1, редирект на HTTPS, HSTS и другие заголовки, версии ПО в заголовках, cookie без Secure, CMS, листинг каталогов, открытые `.git`, `.env`, бэкапы `wp-config`, `phpinfo`, `server-status` (с защитой от «мягких 404») |
| Домен | срок регистрации (RDAP, для .ru/.рф/.su — WHOIS tcinet), количество DNS-серверов, DNSSEC, CAA |
| Порты | ~20 опасных портов сайта и **внешнего IP офиса**: RDP, SMB, базы данных, Redis/Mongo/Elastic, Docker, Telnet, VNC, **1С**, **MikroTik Winbox** |
| Утечки | взлом самого сайта (HIBP, бесплатно); ящики сотрудников — с платным ключом HIBP |

## Согласие — обязательно

Проверка **не запустится**, пока в карточке клиента не отмечено письменное согласие с номером и датой документа
(и не истёк его срок, если он указан). Кнопка «Сформировать бланк согласия» в карточке клиента делает
заполненный шаблон: что проверяется, что не делается, контакт для экстренной остановки. Распечатайте, дайте
подписать, храните скан. Шаблон — отправная точка, покажите его юристу перед первым договором.

Если сайт клиента на общем хостинге, IP сайта принадлежит хостингу: в отчёте это помечено, а порты 21/22/3306
понижены в важности. Для таких клиентов можно снять галочку «Порты» и проверять только IP офиса.

## Запуск

**Вариант 1 — готовый exe.** Запустите `build.bat` (нужен Python 3.11+ с python.org), получите
`dist\SMBCheck.exe` и `dist\SMBCheck-cli.exe`. Или загрузите проект на GitHub: workflow
`.github/workflows/build.yml` соберёт exe на Windows и выложит их в Artifacts.

**Вариант 2 — без сборки.** `run.bat` или `python app.py`.

Неподписанный exe может вызвать предупреждение SmartScreen («Подробнее → Выполнить в любом случае»),
а некоторые антивирусы ругаются на любые сборки PyInstaller. Для продажи клиентам exe стоит подписать сертификатом;
для себя достаточно варианта 2.

## Как пользоваться

1. «Настройки»: ваше имя (попадёт в отчёт), контакт, при желании ключ HIBP.
2. «+ Клиент»: название, домен, ящики сотрудников, внешний IP офиса, данные согласия.
3. Выберите клиента → «Проверить выбранных». Через 1–2 минуты появится отчёт.
4. «Открыть отчёт» → Ctrl+P → «Сохранить как PDF». «Текст для мессенджера» копирует короткую сводку для Telegram/WhatsApp.
5. Через месяц — «Проверить всех»: в отчёте появится блок «Исправлено / Появилось новое».

«Пример отчёта» показывает готовый отчёт без сети — удобно показывать потенциальным клиентам.

## Автоматический ежемесячный запуск

```
schtasks /create /tn "SMBCheck monthly" /sc monthly /d 1 /st 09:00 ^
  /tr "\"C:\путь\к\SMBCheck-cli.exe\" scan-all"
```

Отчёты появятся в папке отчётов, история — в `%APPDATA%\SMBCheck`.

Разовая проверка из командной строки (номер и дата согласия обязательны):

```
SMBCheck-cli.exe check romashka.ru --consent-doc "Договор 12" --consent-date 01.11.2026 --office-ip 81.200.10.20
```

## Где что лежит

- `%APPDATA%\SMBCheck\clients.json` — клиенты; `settings.json` — настройки; `history\<id>\*.json` — все проверки.
- Отчёты — `%APPDATA%\SMBCheck\reports` (меняется в настройках); бланки согласий — в подпапке `согласия`.

Папку `%APPDATA%\SMBCheck` стоит бэкапить: там данные клиентов и ключ HIBP.

## Ограничения (честно)

- DKIM ищется по известным селекторам. Если провайдер использует нестандартный, будет ложное «не найдено»; в отчёте это оговорено.
- DNS спрашивается у публичных резолверов (1.1.1.1, 8.8.8.8, 9.9.9.9), при блокировке порта 53 — через DNS-over-HTTPS.
- Это внешний аудит гигиены, не пентест; формулировка в подвале отчёта это прямо говорит.

## Разработка

```
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Структура: `smbcheck/checks/*` — проверки (функции `analyze_*` без сети легко тестировать),
`scanner.py` — запуск и проверка согласия, `scoring.py` — оценка и сравнение месяцев,
`report.py` — HTML-отчёт, `consent.py` — бланк согласия, `gui.py` — окно, `cli.py` — командная строка.
